# Triage Labels

스킬의 canonical role을 아래 GitHub 라벨로 매핑한다.

| 스킬 역할 | 저장소 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 검토 필요 |
| `needs-info` | `needs-info` | 제보자의 추가 정보 대기 |
| `ready-for-agent` | `ready-for-agent` | 명세가 충분하여 에이전트 구현 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 필요 |
| `wontfix` | `wontfix` | 처리하지 않음 |

스킬이 역할을 언급하면 대응하는 저장소 라벨을 사용한다. 라벨 이름을 변경할 때는 이 표의 저장소 라벨 열을 수정한다.
