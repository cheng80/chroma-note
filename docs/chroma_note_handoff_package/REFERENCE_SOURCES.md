# Chroma Note — Visual Reference Sources

이 파일은 `chroma_note_project_handoff.html` 안에 삽입된 외부 이미지의 원본 페이지와 이미지 URL을 기록한다.

> 이미지들은 핸드오프/리서치 참고 목적으로 외부 원본 URL을 통해 표시된다. 특정 브랜드나 앱의 UI를 그대로 복제하기 위한 자료가 아니다.

## fan_deck

- Source page: https://tecwoodoutdoorfloor.com/blog/mau-pantone-la-gi.html
- Image: https://tecwoodoutdoorfloor.com/upload/images/Blog/bang-mau-pentone.jpg
- Usage note: 컬러 팬덱의 핵심 레퍼런스. 여러 색을 한 축에서 펼쳐 보고, 하나를 골라 실제 물체와 대조하는 물리적 경험을 참고한다.

## pastel_index

- Source page: https://shop.mochithings.com/products/98805
- Image: https://assets-production.mochi.media/products/98805/photos/square_thumbnail_215934-pastel-index-sticky-note-5c6273.jpg
- Usage note: 다이어리 페이지에 파스텔 인덱스가 겹쳐 붙는 모습. Chroma Note의 Color Index가 정보이면서 장식이 되는 방향의 직접적인 참고.

## planner_tabs

- Source page: https://plannersavenue.com/collections/index-tabs-page-flags
- Image: https://plannersavenue.com/cdn/shop/collections/Index_Tabs_and_Page_Flags.png?v=1727742828
- Usage note: 페이지 가장자리에서 색 인덱스가 튀어나오는 구조. Book이 쌓일수록 외곽이 알록달록해지는 경험을 참고한다.

## washi_swatch

- Source page: https://www.archerandolive.com/blogs/news/how-to-create-a-washi-tape-sample-book
- Image: https://cdn.shopify.com/s/files/1/1201/4358/files/Image_2_2cce2808-5491-4250-a592-d3a23e994582.jpg?v=1655902505
