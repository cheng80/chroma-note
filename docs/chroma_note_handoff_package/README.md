# Chroma Note Handoff Package

## 파일

- `chroma_note_project_handoff.html`
  - 권장 열람 파일.
  - 기획 내용의 해당 위치에 실제 웹 레퍼런스 이미지가 삽입되어 있음.
  - 이미지 클릭 시 출처 페이지로 이동.
- `chroma_note_project_handoff.md`
  - 원본 텍스트 핸드오프.
- `REFERENCE_SOURCES.md`
  - HTML에서 사용한 이미지/사이트 출처 목록.

## 중요

HTML의 레퍼런스 이미지는 원본 웹 URL을 사용하므로 이미지 표시에는 인터넷 연결이 필요하다.
텍스트 본문 자체는 로컬에서 그대로 열 수 있다.
