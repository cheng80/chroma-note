# ADR-003 — 선화 기록 설계 결정

- 갱신일: 2026-09-10.
- 상태: 현재 기획에 적용. 아래 설계 기본값은 사용자 개별 승인 이력이 아니다.
- 계약 정본: [제품 명세](../01_PRODUCT_SPEC.md), [기술 명세](../02_TECH_SPEC.md). 입력 출처는 [문서 안내](../README.md#적용-기준과-입력-출처)를 따른다.

## 제품과 범위

사진의 원래 색을 선에 입힌 흰 배경 컬러 선화를 대표색·AI 메모 초안·사용자 메모와 함께 모은다. 핵심 문구 제안은 “그날의 색을, 선으로 남기다.”다. 기록 단위는 선화 기록이며 기존 Stamp Record·DB 식별자는 호환을 위해 유지한다. 사진 처리와 AI는 로컬, 완성 기록 보관은 계정별 Supabase다.

사진 입력은 임포트 전용으로 설계한다. 출시 준비는 이번 범위 밖이고 실제 결제 정책·연동 문서는 Phase 2다. 구현·모델 실행·원격 변경은 별도 요청 범위에서 수행한다.

## 선택 이유와 영향

|---|---|---|

| 계정별 클라우드 Record / 무계정 파일 백업 제외 | 완성 기록을 다른 기기에서 다시 조회. 최초 인증·서버 확정에는 연결 필요 | 기술 §7~9 |
| 원본은 임시 로컬 작업본 / 영구 보관 제외 | 원본 서버 비업로드와 보관 최소화. 저장 후 원본 비교·재생성 불가 | 기술 §2 |
| 로컬 VLM과 선화 변환 분리 / 클라우드 사진 AI·확산 모델 제외 | 원본 개인정보 경계와 실제 장면 보존. 모델 품질·단말 자원 gate 미통과 시 완료 불가 | AI 검증 계획, 현황 PLAN-00~03 |

## 구현 설계 기본값

- 최초 인증 후 계정 귀속 초안. 계정당 이 기기에서 신규 초안 1개와 기존 Record 편집 초안 1개를 관리한다. guest 초안은 제공하지 않는다.
- 인증 이력이 있으면 오프라인 로컬 분석·편집 가능. 서버 변경은 연결·인증 확인 이후 확정한다. 로그아웃은 미저장 경고와 명시 폐기 선택을 거쳐 계정별 로컬 데이터를 정리한다.
- 서버 ready를 확인한 뒤 원본 작업본을 정리한다. 원격 성공이 불명확하면 보존한다. 저장 후 다시 만들려면 사진을 재임포트해 새 Record를 만든다.
- VLM 실패는 사용자 명시 생략을 허용하지만 Stamp 실패는 완성 저장을 허용하지 않는다. 기술 검증에서 생략을 VLM 성공으로 집계하지 않는다.
- 자동 대표색 1~5개, 장소명 직접 입력·좌표 없음, 날짜·태그·즐겨찾기 필터를 제공한다.
- 자체 학습·fine-tuning·LoRA·distillation은 수행하지 않는다. pretrained 모델의 실제 사용조건·변환 품질을 확인한다.
- 2026-09-10 사용자 피드백을 반영한 스타일 1 컬러 선화를 현재 기준으로 삼는다. 원본 주요 피사체·사람 수·배치·세부와 색의 보존, 소요 시간을 평가한다. 과거 ChatGPT 도장과 seed 17 확산 출력은 현재 목표가 아니다. 완벽한 픽셀 복제·얼굴과 손의 완전 보존은 보장하지 않는다. 현재 선화 평가 도구·결과는 [선화 실험](../../experiments/model-selection/LINE_ART_RESEARCH.md)에 기록하고 앱 실사용 결과 확인 UI와 구분한다.
- 사진 처리에서는 Stamp 변환과 태그 분석을 함께 자동 수행해 제공한다. 짧은 문구는 사용자가 노트 작성 중 명시 생성 버튼을 눌렀을 때만 제안하고 자동 사진 처리에서는 비워 둔다. source_revision이 현재 입력과 일치해야 수용하며 user_note는 덮어쓰지 않는다. 모델 비교는 순차 실행을 허용한다.
- 데이터 유실 방지·권한·입력 검증은 축소하지 않는다. 멱등 저장, 버전 충돌, 삭제 후 재생성 방지와 원본 비유출을 기술 계약으로 검증한다.

입출력 상한·PNG·성능 예산은 설계 시작값이며 실측 결과가 아니다. 정확한 스키마와 실패 복구는 기술 명세에서 관리한다.

## 미검증 조건

모델 품질·가중치 사용조건·목표 단말 성능은 문서만으로 확정할 수 없다. [프로젝트 현황](../03_PROJECT_STATUS.md)의 증거 게이트와 [AI 검증 계획](../05_AI_VALIDATION_PLAN.md)을 따른다. 기준 미달이면 자동으로 클라우드나 필터 방식으로 바꾸지 않고 실험 결과를 근거로 범위 변경을 검토한다.
