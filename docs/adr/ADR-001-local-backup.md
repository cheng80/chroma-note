# ADR-001 — V1에 서버 없는 수동 파일 백업·복원을 포함한다

- 상태: 승인
- 날짜: 2026-09-07
- 근거: 기획 보완 인터뷰 Q1·Q10 사용자 답변

원본은 백업을 후속 기능으로 뒀지만, 첫 버전의 목표가 스토어 정식 출시로 확정되면서 기기 교체·재설치에 대비한 기록 보존 범위를 재검토했다. 사용자는 개발·검증 범위 증가를 수용하고 V1에 사진·색·배치를 파일로 백업·복원하는 기능을 포함하기로 했다.

Local-first와 서버·계정 없음은 유지한다. 백업은 사용자가 직접 생성·보관·가져오며 클라우드 동기화나 공유 이미지로 대체하지 않는다. 향후 앱 버전에서도 백업 호환성을 다뤄야 하므로 형식 버전과 실패 시 기존 기록 보존을 기술 계약에 포함한다.

Q14에서 복원은 새 기록 병합, 같은 기록 ID는 현재 기기의 기록 유지로 확정했다. 현재 편집 내용을 보호하는 대신 같은 기록의 다른 기기 수정 내용을 자동으로 합치지 않는다. 사진 기록과 그 하위 색·배치는 한 단위로 건너뛰며, 이 정책을 바꾸려면 데이터 충돌 의미를 다시 검토해야 한다. 구체적인 파일 형식은 구현 설계에서 정한다.

복원하는 사진 기록에는 사용자가 수정한 날짜와 메모도 포함한다. 언어 설정은 현재 기기 설정을 유지하고, 앱에 포함된 읽기 전용 Ideas는 앱이 제공한다. 2026-09-07 최종 사용자 지시로 Q17의 앱 최적화 사본 보관을 재확정했으므로 백업·복원 사진도 해당 사본을 기준으로 한다. 갤러리 접근·재연결에 의존하지 않으며 부분 백업은 채택하지 않는다. 갤러리 참조안 철회 이력은 [ADR-002](ADR-002-gallery-reference.md)에 남겼다.
