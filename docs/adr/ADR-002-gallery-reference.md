# ADR-002 — 갤러리 참조안 철회, 앱 전용 사본 보관 재확정

**상태: 철회 — Q17의 앱 전용 사본 보관으로 대체.** 2026-09-07 사용자가 리서치를 중단하고 사본 저장 방식으로 돌아가도록 명시했다.

용량·사진 관리 부담을 줄이려 갤러리 참조안을 논의했으나, 원본 삭제·보정·권한 변경에도 기록 당시의 사진과 색을 유지하는 이점을 설명한 뒤 사용자가 사본 보관을 다시 선택했다. 앱은 감상용으로 최적화한 사본을 기록의 일부로 자동 관리하며 사진 기록 전체 삭제 시 해당 사본도 정리한다. 갤러리 원본은 변경하지 않는다. 사본의 추가 용량은 남으므로 해상도·압축률은 실제 화질·색·메모리 검증 후 정한다.

Q18~Q21의 사진 재연결·백업 시 갤러리 읽기·원본 변경 후 채집 위치 무효화·부분 백업은 철회한 참조안을 전제로 한 과거 답변이다. 현재 구현 요구로 적용하지 않는다. 백업에는 앱 보관 사본을 포함하고 복원도 앱 내부에서 완료한다. 리서치는 중단했으며 미완성 조사로 업계 표준이나 최적 품질 수치를 확정하지 않았다.
