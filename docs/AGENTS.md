# 문서 작업용 AI 진입점

루트 [AGENTS.md](../AGENTS.md)를 함께 따른다. 이 파일은 문서의 읽기·갱신 경로만 안내한다.

## 읽기 순서

1. [프로젝트 현황](03_PROJECT_STATUS.md)의 현재 작업과 인수인계.
2. 현황에 연결된 활성 계획이 있으면 해당 계획.
3. 관련 [제품 명세](01_PRODUCT_SPEC.md)·[기술 명세](02_TECH_SPEC.md).
4. 관련 코드와 테스트.
5. 작업 절차가 필요하면 [작업 흐름](04_WORKFLOW.md).

## 갱신 위치

- 제품 동작·UI → 제품 명세.
- 구조·데이터·계약 → 기술 명세.
- 진행·다음 작업·검증·인수인계 → 프로젝트 현황.
- 작업 절차 → 작업 흐름.
- 중요한 새 결정의 이유 → 필요할 때 ADR.

기존 핸드오프는 결정 배경으로 보존한다. 확정 요구, 설계 초안, 미구현·미검증 상태를 구별하고 정본 내용을 이 파일에 복사하지 않는다.
