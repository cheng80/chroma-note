# Chroma Note 프로젝트 현황

갱신일: **2026-09-09 (Asia/Seoul)** · 기준 코드: **e3bdf12**.
현재: **빈 앱 + Stamp Record 상세 설계·새 Pen 디자인 / 모델·핵심 기능 미구현**.

## 1. 현재 범위와 변경

사용자는 제공한 신규 기획 팩·Handoff·인포그래픽을 바탕으로 기존 기획 문서 갱신을 요청했다. 후속으로 **출시 범위 제외**, **실제 결제 문서는 Phase 2**, **카메라 대신 사진 임포트 중심**으로 방향을 좁혔다.

- 현재 작업: 제품/화면/데이터/AI/실패 복구 설계와 구현·검증 계획, 후속 요청한 Pen의 파운데이션·컴포넌트·화면 재작성 완료.
- 대상 앱 기능: 임포트 → 대표색 → 로컬 VLM → 원본 보존 Stamp → 사용자 확인·메모 → Supabase 저장 → Book.
- 이번 실행 제외: 앱 구현, 모델 설치·추론, Supabase 프로젝트 변경, 스토어 출시 준비, 결제 문서/연동, 커밋·push.
- 저장소에는 최신 명세·설계 결정·현황만 유지한다. 앱 밖의 사용자 원본과 별도 워크트리·기기는 이번 정리 대상이 아니다.

## 2. 실제 구현 사실

- src/app/_layout.tsx: 헤더 없는 Expo Router Stack.
- src/app/index.tsx: 빈 React Native View.
- Supabase·사진 임포트·대표색·VLM·Stamp·초안·Book은 이 main에 없다.
- package.json에 lint 명령은 있으나 ESLint 설정/직접 의존성과 테스트 러너는 없다. expo lint의 자동 설치를 읽기 전용 검증처럼 실행하지 않는다.
- package-lock.json/yarn.lock 둘 다 존재한다. 의존성 작업 시작 때 기준을 확인하며 이번에는 변경하지 않는다.
- EAS 연결 정보가 있다는 사실을 Development Build나 출시 완료로 쓰지 않는다.

## 3. 설계 기본값으로 닫은 항목

아래는 개별 사용자 답변을 지어낸 것이 아니라 이번 상세 설계의 기본값이다.

| 항목 | 결정 / 계약 위치 |
|---|---|
| 기록 단위 | Stamp 하나+팔레트/글/메모, SR-FR-006~008 |
| 입력 | 시스템 사진 1장 임포트, 카메라·전체 앨범 접근 강요 없음, SR-FR-002 |
| 원본 수명 | 저장 전 초안에 유지, 서버 확정 뒤 제거, 저장 후 재생성 없음, 기술 §2 |
| 초안/오프라인 | 인증 이력 계정에 신규 1개+편집 1개, 서버 성공과 구별, SR-FR-007 |

확정 방향과 기본값 전체는 제품 명세·설계 결정 ADR에 있다. 정책 하나를 바꿀 때 연결된 요구/스키마/검증을 함께 갱신한다.

- 독립 검토: main/gpt-5.6-luna high로 제품·기술·AI 계획·디자인 brief·README·용어집 6개 파일 대조, 핵심 방향 상충 없음.
- 근거 확인: 공식 모델 카드·라이선스·Supabase·Expo 문서 대조. 모델 설치/실행이나 서버 설정 변경은 수행하지 않음.
