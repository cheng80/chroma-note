## 2. 진행 중인 계획

사용자가 실제 구현과 Orca 오케스트레이션을 요청했다. 체크포인트 push 후 Sol high가 작업 순서와 위임 프롬프트를 정리하고, Astra high의 구조·검증, Sol xhigh의 복잡한 구현·통합, Luna max의 일반 구현을 별도 워크트리로 연결한다. 현재 시점에는 앱 코드·의존성 설치를 수행하지 않았다.

- 한 사진 다중 색, 사용자 최종 선택, 하루 횟수 제한 없음, 촬영 후 분석, Local-first, Color Index를 변경하지 않는다.

- 원본에는 과거 테스트 날짜·리비전·실험 결과가 없다. 문서의 “현재 상태”는 기획 방향이며 기능 구현 증거가 아니다.

### 바로 할 일

Q1~Q17과 사본 보관 재확정 지시를 제품·기술 명세·용어집·ADR에 반영했다. 갤러리 참조·재연결·부분 백업은 현재 구현 대상이 아니다. 제품 결정과 남은 구현 설계·실기기 검증을 구별하며, 디코더 호환성·백업 실패 처리·출시 준비를 완료했다고 간주하지 않는다. Orca 작업 분담과 Core 계획을 다음 단계에서 구체화한다. 실패한 기술 실험은 없다. SDK 공식 문서·소스 읽기 조사는 수행했으며 픽셀 접근 실험·빌드는 미실행이다. 유사 앱 리서치는 사용자 지시로 중단했다.

## 8. 변경된 계약

- **문서 운영:** 현재 정본을 제품·기술·현황·작업 흐름으로 나눴다. 원본은 과거 논의와 시각 자료로 보존한다. 정보 위치는 [README](README.md)에 기록했다.

- **기술:** 실행 코드·DB·API 변경 없음. 데이터 모델은 구현 전 초안으로 유지하며 미정 사항을 명시했다.

## 10. 재개 명령

### 역할별 모델 정책 반영 (2026-09-07)

- 사용자 지정 모델·추론 수준과 역할을 [작업 흐름의 모델 정책](04_WORKFLOW.md#역할별-모델-정책)에 기록하고 루트 `AGENTS.md`에서 연결했다. 더 적합한 구성으로 조정할 수 있으며 이유와 실제 호출 구성을 알린다.
- 이번 변경은 운영 지침만 갱신했다. 현재 대화 모델·계정 설정 변경이나 모델 시험 호출은 수행하지 않았다.
- 검증: 역할 4개·추론 수준·문서 참조와 앵커·공백·변경 diff를 확인했다. 앱 코드 변경이 없어 앱 검사는 수행하지 않았다.

### 에이전트 스킬 설정 인수인계 (2026-09-07)

- `CLAUDE.md`와 `docs/agents/issue-tracker.md`, `triage-labels.md`, `domain.md`에 GitHub Issues·기본 triage 라벨 5개·single-context 구성을 설정했다. `to-tickets`, `to-spec`, `triage`, `wayfinder`와 도메인 문서를 소비하는 스킬이 참조한다.

### 실행 안내

저장소 루트에서 필요에 따라 실행한다. 아래는 안내이며 이번 작업의 실행 결과가 아니다.

```sh
git status --short
cat docs/03_PROJECT_STATUS.md
npm run start
```

개발 서버의 플랫폼별 시작은 `npm run ios`, `npm run android`, `npm run web`, TypeScript 검사는 `npx tsc --noEmit`이다. lint는 환경 준비 후 `npm run lint`로 확인한다. 의존성 변경은 ENV-001을 먼저 확인한다. `npm run reset-project`는 기존 디렉터리를 이동·삭제할 수 있어 재개 절차에서 제외한다.
