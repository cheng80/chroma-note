# Context transfer

Continue in the current session when its context is useful. Delegate independent work when available tools and expected benefit justify it; retain integration and verification responsibility.

Use `handoff` when the user needs a portable record for another agent, directory, or collaborator. Include the objective, decisions and reasons, relevant artifact paths, completed checks, pending work, and authorization boundaries.

Compaction depends on the current host and model; no fixed token threshold or phase sequence applies. Preserve unresolved work across compaction. Clear context only when the user requests it or it is known to be disposable and the host supports the action.
